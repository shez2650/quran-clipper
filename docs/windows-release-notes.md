Windows-only feature release: YouTube importing is built into Quran Clipper.

- Copy a YouTube video URL, click **Paste a YouTube link**, and **Import**.
- Includes pinned yt-dlp and Deno: no separate installation, PATH setup, or browser extension.
- Import audio and optional footage into normal projects for playback, marking, stitching, reverb and other exports. Original footage can also be fetched later.
- Preserves progress, cancellation, temporary-file cleanup and saved projects.

Download **QuranClipper-windows.zip**, extract the entire folder, and run **QuranClipper.exe**. Keep the tools folder and DLLs beside the app. Requires Windows 10 or later (x64).

Private, unavailable, region/age-restricted or bot-blocked videos can still be refused by YouTube. No macOS or Android build is included in this release.
